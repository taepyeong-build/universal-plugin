급하게 경영진 회의용 1페이지 의사결정 메모를 바로 써줘.
주제: 다음 분기 사내 고객지원 챗봇의 LLM 모델을 더 비싼 최상위 모델로 교체하자는 의견이 있는데, 나는 모델 교체 대신 평가 데이터셋 구축과 검색(RAG) 청킹 개선에 예산을 먼저 써야 한다고 주장하고 싶어.

알려진 사실:
- 현재 CS 티켓 오답률은 최근 30일 샘플 200건 기준 28%.
- 오답 56건 중 41건은 사내 정책 문서를 잘못 검색했거나 구버전 문서를 가져온 문제였고, 모델 추론 자체 오류는 15건이었다.
- 모델 교체 시 월 API 비용은 현재의 3.2배로 증가한다.
- RAG/평가 개선에는 엔지니어 2명의 3주가 필요하다.
- 목표 오답률이나 정확한 월 API 금액(원 단위)은 아직 재무팀 확인 전이다.

질문하지 말고 바로 작성하되, 경영진이 바로 의사결정할 수 있는 최고 수준 문서로 완성해 줘.
